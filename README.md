# CR7 — The Immortal Legacy

Premium 3D interactive biography site for Cristiano Ronaldo.

## What's inside
- index.html — single-page layout with 4 chronological chapters (Madeira, United, Madrid, Legacy)
- styles.css — cinematic dark theme (gold #D4AF37, crimson, neon), 3D prism cards, glass UI, gold shimmer effects
- script.js — GSAP ScrollTrigger animations, 3D tilt cards, counter animations, parallax mouse tracking, progress bar
- Real Wikimedia Commons photos of Cristiano Ronaldo embedded in cards

## Design
- Dark stadium atmosphere (#08080C)
- Gold / crimson / white typography (Oswald + Inter fonts)
- Spinning wireframe globe background + glowing flare effects
- Responsive layout with mobile hamburger navigation

## To view
Open index.html in any browser. Requires internet for GSAP CDN on first load.
